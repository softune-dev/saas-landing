# Softune Social Post Prompts — 20 Unique Designs

Shared brand system — paste this at the top of every prompt below (or keep it as a running system message if your tool supports one):

```
BRAND SYSTEM (Softune — use exactly, on every image):
Palette:
- Brand Orange #FF5733 — CTAs, highlights, accent words, active states
- Ink Black #0F0F0F — headings, body text, icons
- Muted Grey #6B7280 — subtext, captions
- Surface White #FAF9F6 — backgrounds, card fills
- Border Line #D4D4D4 — card borders, dividers
Type: Plus Jakarta Sans ExtraBold 800 for headlines · Inter Semibold 600 for
labels · Inter Medium 500 for body text.
Exclusions (every image): no real logo/wordmark rendered as readable text —
logo badge stays an abstract Brand-Orange placeholder shape; no real
third-party logos (bKash/Nagad/Visa/courier marks) — use generic rounded
label pills instead; no human faces/hands unless abstract silhouette; no
fabricated specific numbers presented as real data; all on-screen UI text is
short placeholder-style copy, never full sentences.
```
